STEP 2: UPLOAD .HTACCESS.PRODUCTION TO LIVE SERVER
──────────────────────────────────────────────────
You have THREE options:

OPTION A: Via FTP/File Manager (Easiest)
1. Upload .htaccess.production to your live server root
2. Rename it from ".htaccess.production" to ".htaccess"
3. Overwrite existing .htaccess if asked
4. Done!

OPTION B: Via SSH (Recommended)
1. Upload .htaccess.production to live server:
   scp .htaccess.production user@yourserver.com:/path/to/site/

2. Rename it:
   ssh user@yourserver.com
   cd /path/to/your/site
   mv .htaccess.production .htaccess

3. Set permissions:
   chmod 644 .htaccess

4. Done!

──────────────────────────────────────────────────
If your live server has SSL certificate installed:

1. Open .htaccess on live server

================================================================================
  COMMON ISSUES & FIXES
================================================================================

ISSUE #1: All pages show 404 error on live server
──────────────────────────────────────────────────
CAUSE: Wrong RewriteBase setting

FIX:
1. Check if your site is in root or subfolder
   
   If root (yourdomain.com/):
   RewriteBase /
   
   If subfolder (yourdomain.com/subfolder/):
   RewriteBase /subfolder/

2. Update .htaccess accordingly

ISSUE #2: Assets (CSS/JS/Images) not loading (404)
──────────────────────────────────────────────────
CAUSE: RewriteRule paths wrong for root deployment

FIX:
Make sure you have these lines:
RewriteRule ^(assets/.*)$ public/$1 [L,QSA]
RewriteRule ^(resource/.*)$ public/$1 [L,QSA]

NOT:
RewriteRule ^sampro/(assets/.*)$ public/$1 [L,QSA]  ← Wrong for production

ISSUE #3: HTTPS redirect creates infinite loop
──────────────────────────────────────────────────
CAUSE: Server already handles HTTPS or proxy issue

FIX:
Change the HTTPS redirect to:
<IfModule mod_rewrite.c>
    RewriteCond %{HTTPS} off
    RewriteCond %{HTTP:X-Forwarded-Proto} !https
    RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>

Or disable the HTTPS redirect (comment it back out)

ISSUE #4: "Internal Server Error" (500)
──────────────────────────────────────────────────
CAUSE: Apache mod_rewrite not enabled or syntax error

FIX:
1. Enable mod_rewrite on server:
   sudo a2enmod rewrite
   sudo systemctl restart apache2

2. Check .htaccess syntax:
   apachectl configtest

3. Check server error logs:
   tail -f /var/log/apache2/error.log

ISSUE #5: Homepage loads but subpages don't
──────────────────────────────────────────────────
CAUSE: AllowOverride not enabled in Apache config

FIX (requires server access):
Edit Apache config:
sudo nano /etc/apache2/sites-available/yoursite.conf

Add/change:
<Directory /var/www/html>
    AllowOverride All
</Directory>

Restart Apache:
sudo systemctl restart apache2
