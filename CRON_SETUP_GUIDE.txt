================================================================================
  SAMFWARE - CRON JOBS SETUP GUIDE
================================================================================

This guide explains how to set up automated cron jobs for:
1. Firmware Scraper (fetches new firmware data)
2. Firmware Publisher (publishes scheduled posts)

================================================================================
  PREREQUISITES - RUN THESE FIRST ON LIVE SERVER
================================================================================

1. DATABASE MIGRATIONS
   Run this command via SSH on your live server:
   
   cd /path/to/your/site
   php spark migrate
   
   This creates required tables:
   - fw_scraper_cache
   - fw_scraper_log
   - fw_scheduler_log
   - Adds scheduler columns to fw_posts

2. VERIFY TABLES EXIST
   Run in phpMyAdmin or MySQL:
   
   SHOW TABLES LIKE 'fw_scraper%';
   SHOW TABLES LIKE 'fw_scheduler%';
   
   You should see:
   ✓ fw_scraper_cache
   ✓ fw_scraper_log
   ✓ fw_scheduler_log

3. CHECK PHP EXTENSIONS
   Create phpinfo.php and check these are enabled:
   ✓ cURL
   ✓ DOM
   ✓ libxml
   ✓ mbstring
   ✓ mysqli

================================================================================
  CRON JOB #1: FIRMWARE SCRAPER
================================================================================

PURPOSE:
Automatically scrapes new firmware from SXRom.com every 30 minutes

URL TO CALL:
https://yourdomain.com/firmware-scraper/scrape

SCHEDULE:
Every 30 minutes

WHAT IT DOES:
1. Fetches latest firmware list from SXRom.com
2. Extracts device names, models, versions, CSC codes
3. Matches with OdinRom.com for download links
4. Creates new posts as "Draft" status
5. Automatically triggers scheduler to assign publish times
6. Logs everything to fw_scraper_log table

CRON SYNTAX:
*/30 * * * * curl -s "https://yourdomain.com/firmware-scraper/scrape" > /dev/null 2>&1

WITH LOGGING:
*/30 * * * * curl -s "https://yourdomain.com/firmware-scraper/scrape" >> /home/logs/scraper.log 2>&1

================================================================================
  CRON JOB #2: FIRMWARE PUBLISHER
================================================================================

PURPOSE:
Publishes scheduled draft posts at their designated time

URL TO CALL:
https://yourdomain.com/firmware-scheduler/publish

SCHEDULE:
Every 5 minutes (for precise timing)

WHAT IT DOES:
1. Checks for posts where scheduledPublishTime <= NOW
2. Publishes posts with priority (urgent → high → normal)
3. Changes postStatus from 'Draft' to 'Active'
4. Sets publishedAt timestamp
5. Clears cache for immediate visibility
6. Logs to fw_scheduler_log table

CRON SYNTAX:
*/5 * * * * curl -s "https://yourdomain.com/firmware-scheduler/publish" > /dev/null 2>&1

WITH LOGGING:
*/5 * * * * curl -s "https://yourdomain.com/firmware-scheduler/publish" >> /home/logs/publisher.log 2>&1

────────────────────────────────────────────────────────────────────────────
  OPTION C: SSH/VPS/Dedicated Server (Linux)
────────────────────────────────────────────────────────────────────────────

1. SSH into your server:
   ssh username@yourserver.com

2. Edit crontab:
   crontab -e

3. Add these two lines (paste into the editor):

   # Firmware Scraper - Every 30 minutes
   */30 * * * * curl -s "https://yourdomain.com/firmware-scraper/scrape" >> /var/log/scraper.log 2>&1

   # Firmware Publisher - Every 5 minutes
   */5 * * * * curl -s "https://yourdomain.com/firmware-scheduler/publish" >> /var/log/publisher.log 2>&1

4. Save and exit:
   - In nano: Press Ctrl+X, then Y, then Enter
   - In vi/vim: Press Esc, then type :wq and press Enter

5. Verify cron jobs are saved:
   crontab -l

6. Create log directory (if needed):
   mkdir -p /var/log
   chmod 755 /var/log

7. Done!

Replace /path/to/your/site with your actual path like:

================================================================================
  HOW THE SYSTEM WORKS (WORKFLOW)
================================================================================

STEP 1: SCRAPER RUNS (Every 30 minutes)
┌─────────────────────────────────────────┐
│ 1. Fetch latest firmware from SXRom    │
│ 2. Parse 50-100 firmware entries       │
│ 3. Match with OdinRom download links   │
│ 4. Create Draft posts in database      │
│ 5. AUTO-RUN scheduler internally       │
│ 6. Assign priorities + schedule times  │
└─────────────────────────────────────────┘

STEP 2: SCHEDULER ASSIGNS TIMES (Automatic)
┌─────────────────────────────────────────┐
│ • URGENT (new models): 0-2 hours        │
│ • HIGH (popular models): 2-8 hours      │
│ • NORMAL (variants): 8-48 hours         │
│ • Adds random gaps (human-like)        │
└─────────────────────────────────────────┘

STEP 3: PUBLISHER RUNS (Every 5 minutes)
┌─────────────────────────────────────────┐
│ 1. Check: Any post due now?            │
│ 2. If YES: Publish (Draft → Active)    │
│ 3. Set publishedAt timestamp           │
│ 4. Clear cache                         │
│ 5. Log action                          │
└─────────────────────────────────────────┘

EXAMPLE TIMELINE:
02:00 AM - Scraper runs → Finds 50 firmware → Creates 50 Drafts → Auto-schedules
02:15 AM - Publisher runs → Publishes 3 urgent posts
02:20 AM - Publisher runs → Publishes 1 high priority post
04:30 AM - Scraper runs again → Finds 20 new firmware
... continues automatically 24/7

================================================================================
  PRIORITY SYSTEM EXPLANATION
================================================================================

URGENT PRIORITY (Publish in 0-2 hours)
• First time seeing this model
• Brand new device launch
• Example: Galaxy S25 first firmware

HIGH PRIORITY (Publish in 2-8 hours)
• Popular models: S series, Note series, Fold/Flip
• US carriers (XAA, TMB, VZW, ATT)
• Major regions (BTU, DBT)

NORMAL PRIORITY (Publish in 8-48 hours)
• Regular variants
• Less popular regions
• Minor updates

The scheduler spreads posts naturally, never publishing too many at once.

SLOW MODE: 2-4 posts per day (48-hour spread)
NORMAL MODE: 6-12 posts per day (24-hour spread) ← DEFAULT

  SECURITY RECOMMENDATIONS (OPTIONAL BUT RECOMMENDED)

   </FilesMatch>

   Check for errors weekly

================================================================================
  TROUBLESHOOTING COMMON ISSUES
================================================================================

ISSUE: Scraper returns "Whoops" error
FIX:
• Run migrations: php spark migrate
• Check tables exist in database
• Enable PHP extensions: cURL, DOM, mbstring
• Check error logs

ISSUE: Publisher doesn't publish anything
FIX:
• Check if posts have scheduledPublishTime set
• Verify posts are in Draft status
• Check if scheduledPublishTime <= current time
• Look at fw_scheduler_log table for errors

ISSUE: Posts not showing on frontend after publish
FIX:
• Clear browser cache (Ctrl + Shift + R)
• Clear site cache: rm -rf writable/cache/*
• Check postStatus is 'Active' not 'Draft'
• Verify publishedAt timestamp is set

ISSUE: Scraper finds 0 firmware
FIX:
• SXRom.com might be down (check manually)
• HTML structure changed (scraper needs update)
• IP blocked by SXRom (change user-agent or use proxy)

ISSUE: Too many posts publishing at once
FIX:
• Go to Scheduler Dashboard → Settings
• Change Publishing Speed to SLOW or NORMAL
• Click Re-randomize to spread posts out more

ISSUE: Cron jobs not running
FIX:
• Check cron is enabled: service cron status
• Verify crontab syntax: crontab -l
• Check server time zone matches your settings
• Look at mail logs: cat /var/mail/username

================================================================================
  QUICK REFERENCE - CRON SYNTAX
================================================================================

* * * * * command
│ │ │ │ │
│ │ │ │ └─── Day of Week (0-7, Sunday=0 or 7)
│ │ │ └───── Month (1-12)
│ │ └─────── Day of Month (1-31)
│ └───────── Hour (0-23)
└─────────── Minute (0-59)

EXAMPLES:
*/5 * * * *     → Every 5 minutes
*/30 * * * *    → Every 30 minutes
0 * * * *       → Every hour (at minute 0)
0 */6 * * *     → Every 6 hours
0 2 * * *       → Daily at 2:00 AM
0 0 * * 0       → Weekly on Sunday at midnight
0 0 1 * *       → Monthly on 1st at midnight

SPECIAL CHARACTERS:
*   → Every (any value)
*/X → Every X (interval)
X-Y → Range (from X to Y)
X,Y → List (X and Y)
