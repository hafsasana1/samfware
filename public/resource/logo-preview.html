📋 How to Upload the Logo

  1. Go to Admin Panel → Settings → Web Settings
  2. Scroll to Logo Upload section
  3. Click Choose File and select: logo-final.svg
  4. The file is located at: public/resource/logo-final.svg
  5. Click Save Settings
  6. The logo will appear in the header with spinning gear animation!

✨ Logo Features

  • Icon: Orange gear with yellow wrench (from settings.png)
  • Animation: 8-second smooth rotation
  • Text: "Sam" in white + "Fware" in orange (#FF6B35)
  • Size: 400×60px (optimized for header)
  • Format: SVG (scalable, no quality loss)
  • Background: Designed for navy blue (#2C3E50)
